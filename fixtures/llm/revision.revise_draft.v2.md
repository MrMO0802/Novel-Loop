# Chapter 001 Draft

旧货市场的雨棚被雨水压得很低，塑料布一抖，冷水就沿着边缘落进摊位之间的窄路。

林澈把外卖箱往肩上一提，只想从这条路穿过去。摊主却从一堆旧电器后探出半张脸，把一台木壳收音机推到他面前。旋钮上有一圈被刮花的数字，像有人故意抹掉了某一层楼。

“便宜。”摊主说，“带走就行。”

林澈本该拒绝。他看见收音机背后的电池仓空着，也看见指示灯在雨声里亮了一下。那一下很短，短得像错觉。

他付了钱，把旧收音机塞进外卖箱底。离开雨棚时，摊主已经开始收摊，动作快得像终于甩掉了什么。

出租屋里只有台灯亮着。

林澈把旧收音机放在桌上，先拆电池仓，再拆背板。里面没有电池，没有外接线，也没有能解释刚才那点微光的东西。他把螺丝排成一行，告诉自己这只是雨天的反光。

没有电池的收音机忽然发出一声杂音。

林澈的手停在半空。杂音后面，有个很轻的女声断断续续地挤出来：“十七楼……有人吗……”

声音很快被沙沙声吞没。林澈没有把它和任何旧案联系起来。十七楼只是一个尚未解释的楼层谜题，像被刮掉的数字重新从木壳里浮出来。
