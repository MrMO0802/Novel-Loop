# v2.5.0-rc.1 Release Checkpoint

## Status

- Release candidate: `v2.5.0-rc.1`
- Baseline: accepted M26.5 / v2.4.0 Codex single- and multi-chapter pilot baseline
- Package manager: `pnpm@10.12.1` through Corepack
- Runtime target: Node.js 20+

## Release Goal

Package the current Codex pilot baseline into a reproducible release candidate without expanding provider scope.

The release candidate keeps these stable capabilities in scope:

- Deterministic mock three-chapter novel loop through multi-chapter Story State commit.
- Fake Codex regression suite for local CI and release validation.
- FileStore, atomic writes, snapshots, run manifests, event logs, artifact index, audit, retention, provenance compaction, and archive verification.
- Local Codex execution boundary with read-only defaults.
- `provider=codex-text` for Codex-backed strategy, planning, dry-run, draft, and controlled commit.
- Real local Codex single-chapter smoke as a verified pilot workflow when the operator has a working local Codex login.
- M26.5 progressive Codex runtime benchmark as pilot diagnostic tooling.
- Commit Safety Journal for normal mock commit and confirmed Codex controlled commit diagnostics.

Experimental or internal capabilities included in the build but not promoted to stable RC APIs:

- `novel-loop codex multi-chapter-pilot`: experimental pilot only; no production stability guarantee.
- `novel-loop codex profile-runtime`, `novel-loop codex call-reduction`, and `novel-loop codex optimize-runtime`: internal/experimental reports.
- `novel-loop evaluate-continuity`: internal/experimental local drift check.
- `novel-loop prompts audit`: internal prompt-pack inspection.
- `novel-loop providers list`: legacy `real` / `openai` entries are marked `status=legacy-out-of-scope`.

## Explicit Non-Goals

- DeepSeek integration.
- OpenAI API integration.
- Web UI.
- CodexAgentConnector.
- Workspace-write Codex mode.
- Codex historical recommit.
- Codex stale regeneration commit.
- Broad stability guarantees for real Codex multi-chapter runs beyond the accepted pilot baseline.
- M27 output/runtime optimization commitments.

## Required RC Verification

```bash
corepack pnpm install
corepack pnpm build
corepack pnpm test
corepack pnpm novel-loop --version
corepack pnpm novel-loop --help
```

Required mock regression:

```bash
corepack pnpm clean:demo
corepack pnpm novel-loop init demo-novel --brief ./examples/brief.md
corepack pnpm novel-loop build-bible demo-novel --provider mock
corepack pnpm novel-loop plan-global demo-novel --provider mock
corepack pnpm novel-loop chapter demo-novel 1 --provider mock --max-revisions 2 --commit
corepack pnpm novel-loop chapter demo-novel next --provider mock --max-revisions 2 --commit
corepack pnpm novel-loop chapter demo-novel next --provider mock --max-revisions 2 --commit
corepack pnpm novel-loop validate demo-novel
corepack pnpm novel-loop audit demo-novel --strict --fix-index
```

Optional local Codex verification:

```bash
corepack pnpm novel-loop codex status
corepack pnpm novel-loop codex smoke
corepack pnpm run demo:codex-single-chapter
```

Do not make optional real Codex smoke a required CI gate. It depends on local authentication, host performance, installed `codex` binary behavior, and model availability.

## CI Policy

- Required jobs: install, build, test, and non-provider CLI smoke.
- Optional/non-required jobs: local Codex smoke and single-chapter smoke.
- Dependency audit can run as a separate or non-blocking job to avoid blocking the main RC gate on transitive dependency noise.

## Release Safety Notes

- Generated project data under `projects/`, `runs/`, `snapshots/`, `audit/`, `diffs/`, Codex raw artifacts, `.env`, auth files, and token files must not be committed.
- Codex raw outputs are redacted before persistence.
- Story State mutation remains local and schema-gated; Codex never writes `state/story_state.json` directly.
- Controlled Codex commit requires preview artifacts, local validation, conflict checks, approval records, before/after snapshots, and local patch application.
- Normal mock commits and confirmed Codex controlled commits write `commit_journal_vN.json`; audit reports incomplete journals as blocking issues.
- Commit Safety Journal detects incomplete commits through audit; it does not perform automatic recovery.

## Known Limitations

- Real Codex results are environment-dependent.
- Multi-chapter Codex support is a controlled pilot, not a general production SLA.
- Long-form literary quality assessment is outside this RC.
- Commit Safety Journal is a focused diagnostic record, not a broad filesystem transaction manager.
