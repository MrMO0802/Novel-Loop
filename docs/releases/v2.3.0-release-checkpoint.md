Date: 2026-07-04
Baseline: `v2.3.0-codex-single-chapter-loop`

This checkpoint freezes the M25 Codex single-chapter loop baseline before the M26 Codex multi-chapter pilot.

Included:

- TypeScript Node.js CLI baseline.
- Deterministic mock provider and mock multi-chapter baseline.
- Local Codex execution boundary.
- `codex-text` dry-run and draft generation.
- Codex controlled commit for the normal next uncommitted chapter.
- Codex single-chapter smoke command and script.
- Local chapter quality report.
- Preview/confirm consistency report.
- Confirm-by-default preview reuse.
- Hardened Canon Patch proposal normalization.
- Audit integration for Codex reports and controlled commit safety invariants.

Excluded:

- DeepSeek provider.
- OpenAI API provider.
- Web UI.
- CodexAgentConnector.
- Codex workspace-write execution.
- Codex shell-enabled execution.
- Codex historical recommit.
- Codex stale regeneration commit.
- Codex multi-chapter pilot.
